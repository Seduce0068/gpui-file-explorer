## レンズ要約

最大の問題は検索ビューの「Escape 以外を全部捨てる」早期 return で、追加された Ctrl+Shift+F / Ctrl+F 再フォーカス / Enter 到達がことごとく遮断されている点。次いでオーバーレイごとのフォーカス復帰と z 順・キー優先順の不整合、内部 D&D と無効ドロップ先の未処理が目立つ。フォーカス最終挙動のみ GPUI 依存で確度を中に留めた。
